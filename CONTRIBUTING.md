# Contributing to PatPub

Bug reports, documentation improvements, and code contributions are welcome.
Please include a minimal reproduction for defects and describe the source
archive, renderer profile, and release behavior involved. Do not attach USPTO
archives, publication corpora, credentials, Azure resource IDs, or production
data to issues or pull requests. Use small synthetic fixtures instead.

Run the focused checks described in the README before submitting a change.
Keep publication metadata self-contained and static for serving; do not add a
live PatRecords dependency to search or retrieval paths.

By intentionally submitting a contribution for inclusion, you agree that it
is submitted under the Apache License 2.0, as described in section 5 of that
license. Do not submit code or data that you do not have the right to license.
